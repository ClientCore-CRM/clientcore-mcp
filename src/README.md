# MCP калькулятора КП

Слой инструментов над API портала. Цены и правила состава считает портал;
MCP проверяет форму вызова и сохраняет поля при передаче.

- `index.ts`: запуск stdio.
- `server.ts`: определение установки по каталогу и регистрация инструментов.
- `config.ts`: адрес и ключ выбранной установки.
- `api.ts`: HTTP-клиент портала.
- `tools-cc.ts`: инструменты ClientCore, включая ручную цену с причиной.
- `tools-rr.ts`: инструменты Retail Rocket.
- `tools-common.ts`: логотип и ссылки КП для обеих установок.

Бизнес-расчётов и копий каталога здесь быть не должно.
