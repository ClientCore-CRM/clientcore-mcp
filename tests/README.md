# Тесты MCP

- `config.test.ts`: выбор портала по ключу и переменным окружения.
- `tools.test.ts`: реальный MCP transport, доступные инструменты и передача полей в API; ручная цена 0 ₽ сохраняется с причиной, вызов без причины отклоняется до HTTP-записи.

Живые API-токены и запросы в production здесь не используются.
